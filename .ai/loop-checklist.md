# Loop checklist

1. Read `.ai/current-goal.md`, `.ai/goals.md`, `.ai/context.md`, and `.github/copilot-instructions.md`.
2. Confirm the single active step and the files that own it.
3. Edit only the files required for that one step.
4. Run the narrowest validation that exercises the touched slice.
5. Update `.ai/current-goal.md` and `.ai/progress.md`.
6. Stop after that step; do not start a second step in the same loop.
